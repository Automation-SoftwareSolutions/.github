Come funziona
Questa pagina esegue il codice Python direttamente nel browser tramite Pyodide (WebAssembly) — nessun server necessario.

Il file ZIP scaricato contiene il .dxf apribile con AutoCAD, LibreCAD, QCAD, DraftSight.

Per generare il file .step 3D reale (FreeCAD / SolidWorks), usa la versione server:
pip3 install flask cadquery && python3 app.py

I simboli DXF dei fornitori si caricano opzionalmente come ZIP della cartella SIMBOLI/. Senza simboli i componenti vengono disegnati come rettangoli standard.
